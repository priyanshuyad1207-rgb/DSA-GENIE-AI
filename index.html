What We Are Doing

Building a simple DSA learning project that feels practical, not just theoretical

The project shows how common sorting algorithms behave on real input arrays. Instead of only reading time complexity, users can actually watch the process and understand why one approach makes more comparisons, more writes, or fewer overall steps.

What You Can Explore

  • Single algorithm playback with step-by-step tracing
  • Compare mode for side-by-side ranking
  • Array presets like random, nearly sorted, reversed, and few unique
  • Live counters for comparisons, writes, and total steps

Algorithms Included

Seven sorting strategies in one project

The lab currently includes Bubble, Selection, Insertion, Shell, Merge, Quick, and Heap Sort so learners can move from simple basics to faster divide-and-conquer or heap-based approaches.
